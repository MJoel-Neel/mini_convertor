# mini-convertor

A fast, minimal unit converter built with React, TypeScript, and Vite.

Convert values between units across multiple categories — length, temperature, fuel, and more — with instant two-way input: type in either field and the other updates automatically.

## Why this project

Most unit converters are cluttered with ads and unnecessary UI. `mini-convertor` focuses on one thing: converting values quickly and accurately, with a clean interface and no distractions.

## Features

- Instant two-way conversion (type in "from" or "to")
- Multiple dimension categories
- Real-time recalculation when switching units or categories
- Lightweight error handling with toast notifications
- Simple routing with a single-page interface

## Tech stack

- React + TypeScript
- Vite
- React Router
- Sonner (toasts)
- ESLint
